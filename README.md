# KVELOPER

`index.md` 하나를 표시하는 GitHub Pages 사이트입니다.

## 내용 수정

`index.md` 위쪽의 `---`로 감싼 설정은 유지하고 아래 Markdown 본문을 수정한 뒤 GitHub에 커밋·푸시하세요. GitHub Pages가 자동으로 HTML을 만듭니다. 수동 컴파일은 필요하지 않습니다.

저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, 배포 브랜치의 **/(root)**를 선택하세요. 이미 설정되어 있다면 그대로 사용하면 됩니다. 배포에는 잠시 시간이 걸릴 수 있습니다.

## 언어와 폰트

상단 `한국어`는 원문, `English`는 Google Translate로 번역된 페이지를 엽니다. 별도 영어 문서나 API 키 없이 본문 변경도 번역 대상이 됩니다. 영어 번역은 외부 Google 서비스와 공개 배포 URL을 사용하며, 로컬 미리보기에서는 동작하지 않습니다.

기본 글꼴은 SB_Aggro_M, 굵은 글꼴은 SB_Aggro_B입니다. 원본 글리프 전체를 유지한 압축 WOFF 파일 두 개만 포함하므로 새 한국어 문구도 표시됩니다. 페이지에는 JavaScript, 외부 라이브러리, 이미지가 없습니다.
